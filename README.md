## RPCS4 for Android

Android frontend for [RPCS4](https://github.com/rpcs4/rpcs4), built with Kotlin/Jetpack Compose and the original C++23 core through the Android NDK.

## Platform

RPCS4 currently executes PS4 x86-64 code natively, so Android x86_64 is the initial target. ARM64 support requires an x86-64 → AArch64 translator.
